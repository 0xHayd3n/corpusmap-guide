# Improve this reading companion

Corrections, clearer explanations, and better source locators are welcome. The scope is a reading guide to arXiv:2609.37226v1, not an implementation or benchmark reproduction.

For a factual correction, include the relevant repository passage, the paper's exact section/page/table/figure identifier, the versioned primary-source URL, and the replacement explanation. Use original wording. For an interpretation, identify it as such and explain the supporting evidence and its limits.

Keep paper author credit prominent. Do not add private corpus data, credentials, attachment IDs, the PDF, paper screenshots, complete prompts, or copied source material without verifying rights and updating notices. Do not silently update to a later arXiv version. An official code link requires provenance from an author or institution, not a name match.

Run `python scripts/validate.py` from the repository root. Check the edited notes against the original source visually when a table, diagram, or prompt matters. Review numeric units, dataset selections, uncertainty, token aggregation, and the difference between inference and offline construction cost.

The repository's validator checks documentation consistency. Passing it does not verify the paper's results or make a new claim scientifically supported.
